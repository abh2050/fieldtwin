Two scope details matter when using these values:

- Gas volumes include CO2, so they aren't pure hydrocarbon gas.

## Production date versus filing and effective dates

| Field | Status | Canonical column | Meaning |
|---|---|---|---|
| `prodn_yr`, `prodn_mth` | VERIFIED | `reporting_period` | Month and year in which production occurred (OCD dictionary). |
| `eff_dte` | UNRESOLVED | `source_effective_at` | The dictionary says only "The date which the RECORD is effective". Recent values look like processing times shortly after filing, and old values are month-ends. OCD does not define it as a filing date, so it is stored as source_effective_at and must not be used as a production or filing date. |
| `mod_dte` | VERIFIED | `source_modified_at` | Last modified (OCD dictionary). |
| Filing deadline | VERIFIED | Not stored | 15th day of the second month following the month of production (C-115 2025, PDF page 4). |

Measured against this batch:

- `eff_dte` before the production month: 0 rows.
- `eff_dte` inside the production month: 0 rows.
- Non-amended rows with `eff_dte` by the 15th of the second following month: 7,651 of 12,787.

These patterns suggest a processing time, but OCD doesn't define the field that way, so it stays unresolved.

## Amendments

An amended report replaces the operator's earlier file for that month: it "will completely erase and take the place of the old file" (C-115 2025, PDF page 31). The extract therefore holds current values only. amend_ind records that a row came from an amended filing. Earlier values cannot be recovered from this source.

In this batch, 65.2% of rows have `amend_ind = Y`. The one-row-per-key count above agrees with replacement. A consumer sees the latest report only, and revision history can't be rebuilt from one extract.

## Unresolved

- Whether a missing oil or water row means zero. It is kept as missing, not assumed zero.
- An operator's compliance with the rules cannot be verified from this data. The rules establish what was required.
- The state rule copy is amended through 8/23/2022. Later amendments, if any, were not checked.
- Whether a given rule edition applied to each production month was not traced. The 2019 and 2025 instructions state the same units, and the window starts in 2023.
- The meaning of `eff_dte` (above).
- Whether a missing oil or water row means zero. Gas has zero-volume rows, but oil and water have none, so absent rows may mean zero or not reported. `v_production_wide` keeps them NULL.
