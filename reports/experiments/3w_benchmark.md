# 3W benchmark

Generated by `make gate5-reports` from `reports/experiments/results/`.

> **Evidence class: OBSERVED benchmark.** Petrobras 3W is recorded offshore oil-well data, labeled by its publisher. It is an independent benchmark and was never measured at AETHER Field. It covers a deterministic 498-instance subset of 3W 2.0.0, and these results don't establish field-validated detection performance.

## Design

- **Data:** the 299 real instances graded partially labeled. Ambiguous instances are excluded, and simulated and hand-drawn instances appear in one training variant only.
- **Windows:** 300 s, ending on each minute boundary, using only rows at or before the window end. Statistics per sensor are mean, spread, slope, and fraction missing.
- **Splits:** by well. One fold of wells is the holdout. Four development folds compare methods, each setting its threshold on separate validation wells.
- **Operating point:** every threshold sits within 0.05 false alarms per hour and 5% of normal time in alarm on validation wells.
- **Events:** detected only when an alarm episode starts inside the labeled event. Chance level is what unrelated alarms at the measured rate would catch.

Rules: `config/experiments/gate5_evaluation.yaml` and [ADR 0017](../../docs/adr/0017-detection-evaluation-design.md).

## How much a careless split would overstate results

Gradient boosting's sample-level average precision on the same development wells, with three ways of splitting. Only the first is a valid estimate.

| Split | Average precision |
|---|---:|
| By well, as used here | 0.808 |
| By random instance, so a well's other instances train the model | 0.945 |
| By random row, so neighboring windows train the model | 1.000 |

## Limits

- Normal operation comes from only 9 wells, so false-alarm rates on most wells come from the normal rows before events.
- Several classes have too few wells for credible per-class results, and those results are withheld.
- Thresholds aren't tuned per well. A deployed system would usually adapt to each well, which this design deliberately doesn't credit.
- 3W is offshore oil-well data. Nothing here transfers to AETHER or any onshore gas asset.
