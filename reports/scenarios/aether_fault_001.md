# AETHER-FAULT-001: Progressive Gathering-Line Restriction

Generated by `make gate3-reports` from the deterministic simulator. A test fails if this file differs from a fresh run.

> **All values are `SYNTHETIC`.** Synthetic telemetry from a simplified physical model of a fictional well. It is not calibrated to, measured at, or representative of any real well. AETHER Field is a fictional industrial production environment.

## Definition

Fictional Well A-03 delivers through gathering segment GS-A. A restriction develops in that segment, which raises flow resistance and upstream backpressure. No Petrobras 3W or other source telemetry is used.

The model and its assumptions are in the [synthetic telemetry specification](../../docs/product/synthetic_telemetry_spec.md).
