# Reliability stress

Generated by `make gate5-reports` from `reports/experiments/results/`.

> **All values are `SYNTHETIC`.** These runs exercise the simplified, uncalibrated AETHER model, not a validated engineering simulator, and no real operating data.

## Protections

- **Iteration limits:** Newton is capped at 80 iterations and the active set at 16 passes. Both graph walks to suction are now bounded by the node count.
- **Process timeouts:** each run happens in a fresh child process, which is killed at its timeout.
- **Stack capture:** the child dumps every thread's stack just before the timeout.
- **Structured logging:** one JSON line per start and finish.
- **Separate outcomes:** solver nonconvergence, infeasible state, envelope refusal, execution timeout, and crash are reported apart.
